# AGENTS — Master Routing Table

This file lists all agents across all SDLC phases. Orchestrators are user-invocable; sub-agents are dispatched by orchestrators via the `agent` tool.

> **Governing document:** All agents must comply with the **ADO Enforcement** section in [`.github/sdlc-process/micro_waterfall_slide.md`](.github/sdlc-process/micro_waterfall_slide.md) — WI hierarchy, state machines (cdp-core process), branch/PR policies, trust tiers, commit attribution, release gates, and 36 metrics.

> **Wiki-Only Enforcement:** ALL SDLC documentation must be read from and written to the ADO Wiki exclusively. Agents must NEVER create, modify, or store documentation files locally under `docs/`. If wiki or ADO access is unavailable, agents must STOP and ask the user — NEVER fall back to local files.
